# ⚖️ NyayaAI — Nyaya Sahayak

**AI-Powered Legal Intelligence Assistant for BNS & BNSS Section Prediction**

NyayaAI is an intelligent legal assistance platform that leverages **Retrieval-Augmented Generation (RAG)** and **Large Language Models (LLMs)** to analyze legal narratives and predict relevant sections of the **Bharatiya Nyaya Sanhita (BNS)** and **Bharatiya Nagarik Suraksha Sanhita (BNSS)**.

The platform aims to assist law students, legal researchers, and professionals by providing quick access to applicable legal provisions based on case descriptions, FIR narratives, and legal scenarios.

---

## 🚀 Features

* 🔍 **BNS Section Prediction**

  * Identifies relevant sections of the Bharatiya Nyaya Sanhita from user-provided case descriptions.

* 📚 **BNSS Section Recommendation**

  * Suggests procedural sections from the Bharatiya Nagarik Suraksha Sanhita.

* 🤖 **RAG-Based Legal Retrieval**

  * Uses vector embeddings and semantic search for context-aware legal reasoning.

* ⚡ **FastAPI Backend**

  * High-performance REST API for legal intelligence services.

* 🎨 **Modern React Frontend**

  * Responsive and user-friendly interface built with Vite + React.

* 📖 **Explainable Results**

  * Provides relevant legal references alongside predictions.

## ⚙️ Installation

### 1. Clone Repository

```bash
git clone https://github.com/your-username/NyayaAI.git
cd NyayaAI
```

### 2. Create Virtual Environment

```bash
python -m venv venv
```

#### Windows

```bash
venv\Scripts\activate
```

#### Linux / macOS

```bash
source venv/bin/activate
```

### 3. Install Backend Dependencies

```bash
pip install -r requirements.txt
```

---

## ▶️ Running the Backend

```bash
python main.py
```

or

